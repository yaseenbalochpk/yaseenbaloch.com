Not just a portfolio. A digital identity.

05 — Run the Project Locally

The repository can be explored locally using a compatible Node.js environment.

Clone

git clone https://github.com/yaseenbalochpk/yaseenbaloch.com.git
cd yaseenbaloch.com

Install dependencies

npm install

Start the development server

npm run dev

Open "http://localhost:3000" in your browser.

Available scripts

Command| Purpose
"npm run dev"| Start local development
"npm run build"| Build the application for production
"npm run start"| Run the production build
"npm run lint"| Check code quality

Environment note: Use a Node.js version compatible with the project's installed Next.js release. The successful execution of these commands should be verified in your environment.
